``
This project represents the web pages displayed by the Spreadsheet GUI. It is the interaction of the spreadsheet model and the spreadsheet view.

#### Contents of this Project

- It is capable of displaying a GUI representing the spreadsheet model to a user with certain functionality of a typical spreadsheet model.
